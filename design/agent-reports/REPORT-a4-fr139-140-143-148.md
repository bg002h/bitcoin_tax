* **Free finding:** the hand-written usage string was missing `verdict-reach` and `wrapped-literals`. Generating

## 4. FR-140 (F8) — `forms extract` exists, and the finding's fix was INSUFFICIENT as specified

### The numbers, measured

`design/forms/extract/` holds **126** text layers. Before: **74** carried a `# Regenerate:` line — 58 naming
`cargo run -p xtask -- forms extract`, 15 naming `archive_drafts.py --relayout 2026`, 1 a literal `pdftotext`.
**52 carried nothing.** All three counts reproduced by the tool's own first run.

### ★ The refutation, and it matters

FR-140 says: build `forms extract` reading *"each file's own recorded flags"*, and backfill the 52. **The recorded
flags are not enough.** `pdftotext` separates pages with a form feed, and of the 126 committed extracts **72 keep
the form feeds and 54 have them replaced by a newline** — a dimension **nothing recorded**, which cuts straight
through the cohort that named the command: of those 58, **54 are form-feed-stripped and 4 are not**.

So a `forms extract` built exactly to the finding's description would have **rewritten 54 archived authorities on
their page boundaries, and reported success.** That is the shipped-instrument failure class, and it was one
`-layout` away from being introduced by the fix for a finding about missing provenance.

Found by *measuring* rather than by reading: every committed body was run against all four candidate recipes before
any code was written. The header therefore records a fourth field, `form feeds -> LF`, whose absence means the null
transformation (raw `pdftotext` output) — so a header that does not mention page breaks still means exactly one thing.

### How the backfill was done — DERIVED, never asserted

`forms extract --adopt <stem>` does not write down what anyone believes. It runs each candidate recipe and requires
**exactly one to reproduce the committed body byte-for-byte**; if none does it refuses, because a text layer that
`pdftotext` cannot reproduce from the archived document is a provenance claim which would be false the moment it was
written. It verifies **before** writing that the body is unchanged and that the header it derived regenerates the
file it was derived from. The recorded recipe is tried **first**, so a recipe that already works is never swapped for
a different one that happens to work too — on a document with no page breaks both page-break settings reproduce the
body, and preferring the discovered one would strip a correct field out of a header.
