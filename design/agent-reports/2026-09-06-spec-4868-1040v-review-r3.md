### (b) T5(ii) — the 1040-V as a `GRID_MAPS` entry: **half right. The `numbered_line_keys` half is TRUE; the ratchet half is FALSE.** ✗

- **`numbered_line_keys` sees 0 keys for `box1_ssn`-style names — TRUE.** It strips `line` and
  requires a digit (`label_reader.rs:1131-1134`); `box1_ssn` fails at the prefix. `map_reach_problem`
  would then take `(true, 0, _, _) => None` (`:1183`). Verified by reading, and `[census]` entries
  cannot smuggle a binding in either (`line_bindings` requires the LHS to start with `line`).
- **But the walk never gets there.** `every_mapped_line_lands_on_its_own_printed_label` is ordered:

  ```rust
  let join = match label_join(&stem) {
      Ok(j) => j,
      Err(why) => { r.unwitnessed.push(format!("{} — {stem}: {why}", m.form)); continue; }
  };
  ```

  (`label_reader.rs:1613-1619`) — `label_join` → `witness_text` → `Err("no numbered label column
  found — refusing to report zero labels")`, and `continue` skips `numbered_line_keys`,
  `line_bindings` **and** `map_reach_problem` entirely. Measured, not inferred: `xtask label-boxes
  f1040v--2025` prints exactly that refusal today.

  So a committed `f1040v` map lands on `unwitnessed` **regardless of `GRID_MAPS`**, in both years:
  **2025 goes 0 → 1 (over `max_unwitnessed: 0`) and 2024 goes 1 → 2 (over `max_unwitnessed: 1`, already
  spent on `f8283`)** — `audit_year_reach` fails with *"{n} map(s) this check cannot reach, allowance
  is {m}"*. The spec's *"Ratchets: NEITHER moves … the 1040-V is a grid, not an unwitnessed map"* is
  false, and it is false for the same reason r2's N-I2 was: the escape was checked against the rule's
  text and not against the call order.

  Why it looks plausible: **every GRID map on disk today is column-bearing** (`f8949` x2 49.4,
  `f8283` x2 50.4, `f8275` x2 50.4), so no grid map has ever taken the `Err` path. The 1040-V is the
  corpus's first caption-only form, and this interaction has never been exercised.

**The honest fix (pick one, and say which):**
1. **Decide the grid case before the join.** In the walk, read `numbered_line_keys` first; if it is 0
   **and** `GRID_MAPS` names `(year, form)`, record the map in a third, printed bucket ("grid — {reason}")
   and `continue` **without** counting it unwitnessed. Keep `map_reach_problem`'s `(false, 0, …)` arm
   on the other branch so a keyless map that is *not* declared still reds. Smallest change, keeps
   `witness_text`'s "refusing to report zero labels" guard intact for every other form, and the B1 kill
   writes itself (a keyless, undeclared map with no column must still red).
2. **`label_join` consults `GRID_MAPS`** (it can, via `stem_year`) and returns `Ok` with every box `"?"`
   for a declared grid. Acceptable, but it moves the guard's scope into the join.
3. **Raising `max_unwitnessed`** is the dishonest one. It makes *"the reader could not read this form"*
   and *"this form is a declared grid"* look identical in the ratchet — the L5 lesson the `GRID_MAPS`
   list exists to enforce ("the two blanks must never look alike"). Do not.

**Verdict (b): NOT RESOLVED — the spec's "neither ratchet moves" would move both. → N3-I2 (Important).**
